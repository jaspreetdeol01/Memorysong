# BrainSong Landing Page

A NASA-researched audio landing page helping over 16,000 people support their memory and mental clarity.

## Features

- Fully responsive design
- Mobile-friendly layout
- Video integration
- Social proof testimonials
- CTA buttons linking to main presentation

## Deployment

### Deploy to Vercel

1. Go to [vercel.com](https://vercel.com)
2. Click "Add New Project"
3. Import this repository: `jaspreetdeol01/Memorysong`
4. Click "Deploy"

Vercel will automatically detect the HTML file and deploy it.

### Alternative: Direct Import

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/jaspreetdeol01/Memorysong)

## Files

- `index.html` - Main landing page
- `vercel.json` - Vercel deployment configuration

## Local Development

Simply open `index.html` in your browser to view the landing page locally.
